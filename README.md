## ODIN 2026 - WCAG + AI

Resources, open-source projects and AI research related to my presentation at **ODIN 2026 (19 November 2026)**, exploring how AI can help build, test and improve digital accessibility against WCAG 2.2.

| Project | Description | GitHub | Live demo / Model |
|---|---|---|---|
| **UUstreak** | Automated monitoring and ranking of WCAG violations across Norwegian websites. | [Repository](https://github.com/turbolego/uustreak) | [uustreak.no](https://uustreak.no) |
| **AI-WCAG-Gauntlet** | Benchmark for AI-generated websites. AI agents build, test and iteratively fix websites using accessibility validators. | [Repository](https://github.com/turbolego/AI-WCAG-Gauntlet) | [Live demo](https://turbolego.github.io/AI-WCAG-Gauntlet/) |
| **WCAG Skill** | Reusable instructions and tools that help AI coding agents build, audit and repair websites according to WCAG 2.2. | [GitHub](https://github.com/turbolego/wcag-skill) | [ClawHub](https://clawhub.ai/turbolego/skills/wcag-skill) |
| **LayaWCAG** | AI model for identifying and classifying potential WCAG 2.2 violations in HTML. | [Repository](https://github.com/turbolego/LayaWCAG) | [Live demo](https://turbolego.github.io/LayaWCAG/) · [Hugging Face](https://huggingface.co/Turbolego/laya-wcag) |
| **abideWCAG** | Tools for making AI coding agents follow accessibility requirements and project-specific rules. | [Repository](https://github.com/turbolego/abideWCAG) | [Live demo](https://turbolego.github.io/abideWCAG/) |
| **VegaML WCAG** | Experimental machine learning framework exploring calibrated predictions, uncertainty and abstention for WCAG classification. | [Repository](https://github.com/turbolego/vegaml-wcag) | [Live demo](https://turbolego.github.io/vegaml-wcag/wcag-demo/?backend=modal) · [Embedding model](https://huggingface.co/Turbolego/vegaml-wcag-embed-v1) |
| **Qwen3.5-0.8B WCAG Gauntlet LoRA** | Lightweight fine-tuned model for accessibility validator selection and tool-use decisions. | [Repository](https://github.com/turbolego/qwen3.5-0.8b-wcag-gauntlet-lora) | [Hugging Face](https://huggingface.co/Turbolego/qwen3.5-0.8b-wcag-gauntlet-lora) |
| **Qwen2.5-Coder-7B WCAG Gauntlet LoRA** | Fine-tuned coding model incorporating WCAG Gauntlet tool-use capabilities. | [Repository](https://github.com/turbolego/qwen2.5-coder-7b-wcag-gauntlet-lora) | [Hugging Face](https://huggingface.co/Turbolego/qwen2.5-coder-7b-wcag-gauntlet-lora) |
| **Qwen3-Coder-30B-A3B WCAG Gauntlet Adapter** | GGUF LoRA adapter bringing WCAG Gauntlet capabilities to a larger coding model for local inference. | [Repository](https://github.com/turbolego/wcag-gauntlet-30b-a3b-gguf-adapter) | [Hugging Face](https://huggingface.co/Turbolego/wcag-gauntlet-30b-a3b-gguf-adapter) |
